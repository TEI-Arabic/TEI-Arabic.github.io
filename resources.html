Resources

Reference materials, tools, and models for scholars encoding Arabic-script texts in TEI.

  • The TEI Guidelines ↗ The full P5 Guidelines from the Text Encoding Initiative Consortium.
  • TEI Elements Reference ↗ Alphabetical reference for every element in the TEI Guidelines.
  • Oxygen TEI Plugin In Oxygen, go to Preferences > Add-ons, click "Add," and paste https://tei-c.org/release/oxygen/updateSite.oxygen into the URL box.
  • Oxygen XML Editor ↗ A widely used editor for working in TEI's Author mode.
  • TEI Boilerplate for Arabic Editions ↗ A version of TEI Boilerplate adapted for Arabic: RTL support, the Amiri typeface, and browser-side rendering of TEI XML with no server required.
  • Till Grallert's Open Arabic Periodical Editions ↗ TEI editions of early Arabic periodicals.
  • Arabic TEI Workshop — Examples Repository ↗ Sample encoded files from the 2021 Arabic TEI XML Digital Workshop.
  • Introduction to TEI (slides) ↗ Hugh Cayless's introductory slides from the same workshop.
  • Arabic TEI Workshop — YouTube channel ↗ Recorded walkthroughs on markup, GitHub, and Oxygen.

Getting started: a short glossary

Commit
Registering changes to a document in Git. Commit often — each commit is a timestamped point you can search and restore later.
Push
Uploading your commits to GitHub, synchronizing your local work with the shared repository.
Pull
Downloading the latest changes from GitHub to your computer. Start collaborative work with a pull.
Creating an element (Oxygen, Author mode)
Highlight the text, press Ctrl-E (Windows) or Cmd-E (Mac), then choose the element from the menu or type into the search box and hit Enter.
Creating an attribute (Oxygen, Author mode)
Double-click the element and add the attribute's name and value in the menu that appears.
